# 字帖小助手 · Copybook Helper（Web 版）

免费、免注册、**纯前端离线**的字帖模板与生成器。输入汉字 / 拼音 / 英文 / 古诗，自动标注读音、描红临摹、分页排版，一键打印或「另存为 PDF」。

> 本目录（`web/`）是网站版。后续 iOS / Android / 小程序版本与本项目并列，可复用 `assets/js/core/` 全部排版逻辑。

## 功能模块总览

| 模块 | 说明 |
|---|---|
| 模板库 | 31 种预设版式，点击即套用，自动切换参数与示例内容 |
| 生成器 | 左侧控制面板 + 右侧 A4 实时预览，所见即所得 |
| 拼音引擎 | 内置 20992 字离线拼音库，6200+ 多音字候选可点击切换校对 |
| 描红临摹 | 示范格 + N 个练习格，描红深浅 5%–60% 可调 |
| 字格体系 | 12 种格型矢量绘制，缩放打印不变形 |
| 排版分页 | 行列数、格距、页边距自由调节，自动分页 + 尾页补格 |
| 页眉页脚 | 标题、姓名/班级/日期信息栏、评分栏、落款行、页码 |
| 素材库 | 30 首小学必背古诗、三字经、弟子规、千字文、百家姓、拼音表、字母、数字算式、成语、启蒙识字 |
| 导出 | 浏览器打印 / 另存 PDF（矢量输出，A4 100% 尺寸精准）、配置 JSON 导出 |
| 体验 | 深浅双主题、localStorage 自动保存、键盘 Esc、响应式布局 |

## 字帖模板（32 种）

**基础版式（16 种）**：拼音田字格 · 米字格描红 · 米字回宫格 · 回宫格 · 九宫格 · 拼音四线三格 · 英文四线三格 · 数字练习 · 古诗竖排（右起）· 古诗方格抄写 · 作文稿纸 · 姓名练习 · 基本笔画（24 个笔画）· 控笔训练（8 种图案）· 空白练习纸 · 硬笔作品纸

字格类型：田字格 / 米字格 / 米字回宫格 / 回宫格 / 九宫格 / 方格 / 中蛋田字格 / 蛋格 / 中心格 / 四线三格 / 单行横线 / **竖线格** / 无格线（横线格与竖线格均支持实线 / 虚线切换）

## 快速开始

```bash
cd web
python3 -m http.server 8770
# 打开 http://127.0.0.1:8770
```

也可以直接双击 `index.html`（全站零依赖、零构建、无网络请求）。

## 手机版 / iPhone 外壳版

`mobile.html` 用一个 iPhone 金属外壳包裹字帖界面，外壳内是手机自适应布局：**顶部状态栏 + 灵动岛 + 字帖预览主区 + 底部玻璃工具栏 + 底部毛玻璃抽屉**。底部工具栏六个入口——模板 / 内容 / 拼音 / 设置 / 打印 / 主题，点开即调参，预览实时更新。适合手机访问，也像产品展示页一样把字帖效果装进 iPhone 里。

- 在线：https://jdb156158.github.io/copybook/mobile.html
- 本地：`python3 -m http.server 8770` 后打开 `http://127.0.0.1:8770/mobile.html`
- 只想用手机布局、不要外壳：直接访问 `index.html?phone=1`（同一套控件与渲染，桌面端 URL 加参数即可切换）

实现上，手机版与桌面版**共用全部业务逻辑与控件**：`?phone=1` 时 `app.js` 把左侧面板里的「练习内容 / 拼音校对 / 字格与样式」和模板库重排进底部抽屉，预览区自适应屏幕宽度，不复制任何业务代码。

**打印**：点击「打印 / 存 PDF」→ 纸张选 A4、缩放 100% → 得到与预览一致的字帖；需要 PDF 时打印机选「另存为 PDF」。格线为 SVG 矢量元素，无需勾选「背景图形」也完整打印。

## 技术实现要点

- **零依赖**：无框架、无构建、无外部请求；`core/` 层以 IIFE + 全局命名空间编写，Node 里可直接 `vm` 加载做单元测试。
- **矢量格线**：每格一个内联 SVG（`viewBox 0 0 100 100` + `vector-effect: non-scaling-stroke`），任意尺寸不变形，打印即矢量。
- **分页引擎**：`layout.js` 以毫米为基准换算 px（96dpi），按行高、页眉高、可用高度计算每页行数；竖排（右起）与横排双模式独立度量。
- **多音字校对**：默认取最常用读音，面板「拼音校对」点击循环切换候选，覆盖结果持久化并参与渲染。
- **模板 = 配置**：每个模板只是一份 settings 覆盖 + 一段示例文本；新增模板只需在 `templates.js` 追加一条记录。
- **打印精度**：A4 按物理毫米换算（794×1123px @96dpi），`@page` 尺寸随纸张设置动态注入，缩放 100% 打印即 1:1。

## 部署（GitHub Pages）

站点源文件位于本目录 `web/`。仓库通过 `gh-pages` 分支发布：`gh-pages` 分支根目录即 `web/` 的全部内容，GitHub Pages 从 `gh-pages` 分支的根目录提供服务，访问地址为 https://jdb156158.github.io/copybook/ 。

```bash
# 把 web/ 子目录推送到 gh-pages 分支（首次或更新）
git subtree push --prefix web origin gh-pages
```

也可在仓库 Settings → Pages 中确认 Source 为 `Deploy from a branch` → `gh-pages` / `root`。
